# Тоннель

Игра для iPhone (Swift + SpriteKit), вид сверху. Человечек идёт по тоннелю, ты ведёшь его пальцем влево-вправо и обходишь препятствия: ящики, шипы и движущиеся пилы.

- **Случайный тоннель** — каждый раз новая расстановка.
- **Редактор** — расставляй свои препятствия, 5 слотов для уровней.
- **Обмен** — «Поделиться» отправляет код уровня, «Импорт» читает код из буфера обмена.
- **Ловушки:** ящики, шипы, пилы, мигающие лазеры и лужи (замедляют).
- **Настройки:** звук, вибрация, сброс рекордов; рекорд хранится отдельно для каждого слота.
- Графика, звуки и иконка создаются кодом или скриптом, внешних файлов нет.

## Запуск (нужен Mac с Xcode)
```
brew install xcodegen
cd RunnerGame
xcodegen generate
open Runner.xcodeproj
```
Выберите iPhone (симулятор или устройство) и нажмите Run. Для реального устройства укажите свою Team в Signing.
