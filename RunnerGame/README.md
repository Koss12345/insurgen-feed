# Runner

Игра: тоннель, вид сверху. Человечек идёт вперёд, ты ведёшь его пальцем влево-вправо и обходишь препятствия. В редакторе можно расставить свои препятствия и пройти собственный уровень.

## Запуск (нужен Mac с Xcode)
```
brew install xcodegen
cd RunnerGame
xcodegen generate
open Runner.xcodeproj
```
Выберите iPhone (симулятор или устройство) и нажмите Run. Для реального устройства укажите свою Team в Signing.
