# Тоннель — мини-приложение Telegram

Веб-аналог iPhone-игры из `RunnerGame/`: вид сверху, человечек бежит по тоннелю, ты ведёшь его пальцем и обходишь ящики, шипы, пилы, лазеры и лужи.
Чистый JS + Canvas, без сборки и зависимостей.

- 3 мира: Подвал, Лёд (скользко), Лава
- Редактор: 7 кистей, 5 слотов, листание перетаскиванием
- Обмен уровнями кодом `TUNNEL1:…` — **формат совместим с iOS-версией**
- Достижения, рекорды по мирам и слотам
- Прогресс хранится в `localStorage` и дублируется в Telegram CloudStorage (подтягивается на новом устройстве)
- Haptic feedback, нативная кнопка «Назад», отключён свайп вниз (не закрывает игру), звуки и музыка синтезируются WebAudio

## Файлы
- `level.js` — логика без DOM: уровни, миры, коллизии, коды обмена, движение
- `app.js` — отрисовка, ввод, экраны, редактор, интеграция с Telegram
- `index.html`, `style.css` — интерфейс
- `test/level.test.js` — тесты логики

## Проверка локально
```
cd TunnelMiniApp
npm test                 # тесты логики (Node 18+)
python3 -m http.server   # открыть http://localhost:8000
```
Для отладки: `?god` в адресе — бессмертие.

## Публикация в Telegram
1. Выложить папку по HTTPS, например на GitHub Pages.
2. В @BotFather: `/newbot` (если бота нет), затем `/newapp` и указать URL игры — получится ссылка вида `https://t.me/<бот>/<короткое_имя>`.
3. Вписать эту ссылку в `APP_LINK` в начале `app.js`. После этого «Поделиться» отправляет ссылку, которая сразу открывает уровень у друга (через `startapp`), если код влезает в 512 символов. Иначе отправляется сам код.

## Чего нет
Глобальной таблицы лидеров: ей нужен бэкенд (бот + база), проверяющий `initData`. Вместо неё — личные рекорды и кнопка «Поделиться результатом».
